دفتر شماره‌ها — بسته سورس اندروید آفلاین

مهم: این ZIP شامل سورس و فایل‌های ساخت است؛ APK کامپایل‌شده نیست.
برای ساخت APK لازم است Node.js و Android Studio/Android SDK روی ویندوز نصب باشند.

۱) نصب Node.js
از https://nodejs.org نسخه LTS را نصب کن، سپس ترمینال‌ها را ببند و دوباره باز کن.

۲) ZIP را استخراج کن و وارد پوشه mobile-number-android-complete شو.
روی 1-نصب-وابستگی‌ها.bat دوبار کلیک کن. نصب بسته‌ها به اینترنت نیاز دارد.

۳) روی 2-ساخت-پروژه-اندروید.bat دوبار کلیک کن و منتظر پایان build/sync بمان.

۴) Android Studio را نصب و اجرا کن. از Open، پوشه android داخل پروژه را باز کن.
پس از پایان Gradle Sync از منو انتخاب کن:
Build > Build Bundle(s) / APK(s) > Build APK(s)

فایل APK معمولاً در این مسیر است:
android/app/build/outputs/apk/debug/app-debug.apk

پس از تغییر رابط، فایل 2-ساخت-پروژه-اندروید.bat را دوباره اجرا کن و APK را مجدداً بساز.

مخاطبان در localStorage همان برنامه/گوشی ذخیره می‌شوند و اینترنت نمی‌خواهند.
با پاک‌کردن داده‌های برنامه یا حذف آن ممکن است اطلاعات پاک شوند.
اگر خطا دیدی، عکس یا متن کامل خطا را بفرست.
